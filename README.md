# TeamUp

TeamUp is a platform that helps university students find compatible teammates for competitions and collaborative projects.

## Problem

Students often struggle to find teammates with complementary skills and relevant experience. Existing friends may not have all the skills required for a competition.

## Solution

TeamUp helps students:

- Create verified student profiles
- Showcase skills and previous projects
- Add GitHub and portfolio links
- Discover competitions
- Create teams with existing friends
- Find teammates who fill missing skill gaps
- Connect and communicate with potential teammates
